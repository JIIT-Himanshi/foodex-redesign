# Foodex India Redesign

Foodex India Redesign is a modern React-based redesign of the official Foodex India website, focused on delivering a premium user experience through clean layouts, smooth animations, responsive design, and modern UI/UX principles.

The project showcases Foodex's premium namkeen, sweets, gift packs, cookies, and ready-to-eat products while maintaining the brand's traditional identity with a fresh, contemporary visual language.
